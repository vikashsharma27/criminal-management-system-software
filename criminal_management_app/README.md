# 🗂️ Criminal Management System Software (App Module)

This directory contains the Streamlit application code, assets, configuration, and launch scripts.

## 📁 Files in this folder
- `app.py` - Core Streamlit application and database interface.
- `requirements.txt` - Python package dependencies.
- `run.bat` - Windows launch script.
- `run.sh` - Linux/macOS launch script.
- `IMAGE/` - Application branding assets (`LOGO2.png`).
- `.streamlit/` - Configuration (`config.toml`) and secrets template (`secrets.example.toml`).

## 🚀 How to Run
```bash
python -m streamlit run app.py
```

For full documentation and online deployment instructions, view the root [README.md](../README.md).
